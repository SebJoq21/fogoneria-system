# Instrucciones de la Skill BrandKit

Cuando el usuario pida definir una marca o sistema visual:
1. Analiza el propósito del proyecto y la audiencia objetivo.
2. Propón 3 paletas de colores distintas (con códigos HEX, Tailwind classes y contraste WCAG AAA).
3. Selecciona una combinación tipográfica moderna de Google Fonts (Titulares + Texto de cuerpo).
4. Define el estilo conceptual para logotipos e ilustraciones (ej. Minimalista, Neo-brutalismo, Flat 2D, Glassmorphism).
5. Escribe los resultados estructurados directamente en el archivo `DESIGN.md`.
