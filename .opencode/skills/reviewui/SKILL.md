# Instrucciones de la Skill ReviewUI

Al auditar la interfaz web:
1. Conéctate a `localhost:5173` usando el MCP de Playwright.
2. Toma una captura de pantalla de la página en ejecución.
3. Compara visualmente la captura con el archivo de diseño o imagen de referencia (`wireframe.png`).
4. Revisa padding, alineación, colores y jerarquía visual.
5. Si encuentras inconsistencias, edita directamente el código CSS/JSX correspondiente para corregirlo.
