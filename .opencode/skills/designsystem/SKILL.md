# Instrucciones de la Skill DesignSystem

Al generar componentes Frontend:
1. Lee primero `DESIGN.md` para extraer variables de color, tipografía y espaciado.
2. Usa **React (TypeScript)** + **Tailwind CSS**.
3. Asegura que los componentes sean 100% responsivos (Mobile-First).
4. Aplica componentes accesibles (ARIA labels, navegación por teclado).
5. Mantén código limpio: componentes pequeños, desacoplados y en la carpeta `/src/components`.
